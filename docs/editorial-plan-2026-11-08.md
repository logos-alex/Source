## 2. מה מצא הסקר — חמישה ממצאים מרכזיים

1. **הארכיון הישן הוא מכרה**: `LOGIA-final (8).zip` — **31 חיבורים, 653 פרקים, 536,744 מילים**, כולל 27 החיבורים שריקים באתר היום. בנוסף, היסטוריית git לבדה מחזיקה **נדבך פרשנות לחזון אברהם — 17 קטעים, 9,441 מילים** שאינו בשום ארכיון.
2. **אין תבנית מבוא**: שלוש תבניות שונות, חמישה דפוסי כותרות-פרק, שלוש שיטות הערות.
3. **41 עוגני הערה שבורים** בנוסח ד' של חזון אברהם (`[N]` → `#note-N` שאינו נוצר).
4. **27 עמודי „בקרוב”** עם גוף של שורה אחת — אך עם תיאור מלא, וכולם היו באינדקס ובחיפוש (תוקן).
5. **ביבליוגרפיה שגויה בנוסח ד'**: „Апокриф Авраама, ТОДРЛ 2021” — מהדורה שאינה קיימת. המהדורה האמיתית: **„Толковая Палея расширенного состава”, שני כרכים, מילקוב–קמצ'טנוב–קוזלובה**. כמו־כן: 5 מ-7 „שמות ייחודיים” של נוסח ד' מצויים גם בנוסח א'.

## 4. מה עוד פתוח — לפי סדר עדיפות

### א. השלמת תיקונים ידועים (מהיר)
- ביבליוגרפיה של נוסח ד' (§2.5) + הסרת טענת „שמות ייחודיים”.
- 41 עוגני ההערה של נוסח ד'.
- 20 קישורים שבורים בארבעה קובצי index.
- „מעשה יצחק”: ציון הטווח (ff. 98–101) שגוי — ff. 95–100 בקירוב; פרקים 1–3 אינם ניתנים לאימות (אין תמלול).

### ב. תבנית מבוא אחידה (בינונית)
תבנית אחת לכל החיבורים הפעילים:
1. פסקת פתיחה — מה החיבור (2 פסקאות).
2. `## מסעו של החיבור` — מסירה, כתבי-יד, מהדורה.
3. `## מקומו במסורת ישראל` — מקבילות בחז"ל ובמדרש.
4. `## פרקי החיבור` — רשימת פרקים עם שורה לכל אחד.
5. `## מקורות` — ביבליוגרפיה.

### ג. החזרת 27 החיבורים (העיקר)
**עיקרון:** אין חיבור עולה לאוויר בלי אימות מול מקור בשפתו. לכן — **גלים של 3–5 חיבורים**: העברה מהארכיון → אימות 3–5 נקודות-ביקורת → תיקון → `comingSoon: false` → פרסום.

**גל 1 (מקורות ביד):** כתב אלמגאל · חזון עזרא הסורי · חזון דניאל הצעיר · חזון פטרוס · ספר זרובבל.
**גל 2:** חזון דניאל הערבי/הקופטי/הארמני · חזון עזרא הלטיני · קללות השבטים.
**גל 3:** מעלה ישעיהו · אפוקליפסיס אסדרס · חנוך א (יווני) · חנוך קומראן · חזון חנוך הארמני · צוואת ישוע.
**מוחרג בהחלטה:** קלמנטינים (r1–r4, הומיליות, קלמנטוס) — פרויקט-על בפני עצמו.

17 קטעים, 9,441 מילים — לשחזר כפרקי-פירוש נפרדים או כשכבת ביאור.

## 5. כללי-עבודה שנשמרים

1. אין להסיק מהיעדר בתעתיק על תוכן כתב-היד — רק מול הסריקה.
2. אין לפרסם חיבור בלי מקור בשפתו ואימות נקודתי.
3. כל שינוי עובר `npm run ci:verify` (16 בדיקות) לפני push.
4. תיקון-נוסח נרשם במפורש בהיסטוריית git — לא מוחקים, מתקנים.
